StudyMate – Peer Study Partner
Open index.html in any browser. No installation needed.
Files: index.html (structure), style.css (design), data.js (50 sample students), app.js (logic)

Features: Discover + filters + match %, Connect, Request status (pending/accepted/declined),
Chat with auto-replies, Create profile with live preview, data saved in localStorage.
Demo tip: send a request - it gets accepted/declined automatically in a few seconds.
Colors: neutral palette FAF9F7, E4E0DA, C9C3BA, 6B675F, 2B2A28
